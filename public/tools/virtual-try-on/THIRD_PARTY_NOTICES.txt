1. Upstream browser-native virtual try-on project
Project: pravoobi/try-on
Repository: https://github.com/pravoobi/try-on
Live reference deployment: https://pravoobi.github.io/try-on/

The LP-098 candidate intentionally uses the upstream reference deployment while LayerPorter migrates the same published core into its own build. This replaces the rejected LayerPorter custom geometric-warp prototype.

The upstream project describes the browser pipeline as:
- person segmentation;
- pose estimation;
- thin-plate-spline garment warp;
- person-mask / arm occlusion compositing;
- optional garment-upload matting and clothes parsing.

2. Published core package
Package: @practics/tryon-core
Pinned integration target: 0.2.0
Repository: https://github.com/pravoobi/try-on/tree/main/packages/tryon-core
License: MIT

The published package is framework-free and exposes the same pipeline used by the upstream application, including ready-made inference/matting/depth worker factories.

3. Garment upload / extraction path in upstream
The upstream matting worker uses a background-removal model plus a clothes-parsing model to isolate a garment from an uploaded image. Its extraction logic explicitly returns an error when a person is detected but a target garment cannot be isolated, instead of treating the whole source image as a garment.
