# LP-094 — МИТ: проприетарная лицензия Website Image Optimizer MCP

Дата: 2026-09-10
Issue: #218

## Решение владельца

Код и пакет не открываются для свободного копирования. Разрешается только установка и использование официального неизменённого пакета в рамках его назначения. Свободное копирование, изменение, создание производных работ, перепаковка, распространение, зеркалирование, сублицензирование и перепродажа запрещены.

## Почему не `UNLICENSED`

Публичный npm-пакет технически доступен для скачивания. Полный запрет на любые копии конфликтовал бы с самой установкой и запуском через пакетный менеджер. Поэтому используется собственная проприетарная лицензия: она разрешает только технически необходимые копии для установки/исполнения/кэша/резервной копии и не передаёт права на модификацию или распространение.

## Метаданные

`package.json`:
- `license = SEE LICENSE IN LICENSE`
- файл `LICENSE` включён в пакет

## Ограничения

Лицензия не является технической DRM-защитой. Публичный npm не может физически помешать скачиванию байтов; защита здесь юридическая и договорная. Репозиторий проекта остаётся приватным.

## Проверка

1. Preflight проверяет точное значение license metadata и наличие proprietary LICENSE.
2. `npm pack` проверяется на наличие `LICENSE` и совпадение текста лицензии.
3. Clean install + stdio smoke подтверждают, что добавление лицензии не ломает runtime.
4. Полный session gate подтверждает отсутствие регрессии сайта и MCP-контура.
