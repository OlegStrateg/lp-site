# LayerPorter — команда и навыки

Статус: рабочая матрица.
Принцип: не раздувать штат ролями. Один ведущий контур + подключаемые специалисты по необходимости.

## Ядро команды

### 1. Руководитель продукта и проекта
Отвечает за:
- Парето;
- бизнес-эффект;
- порядок реализации;
- зависимости;
- анти-переусложнение;
- критерии готовности;
- принятие/отбрасывание инициатив.

### 2. Технический архитектор сайта и общего ядра
Навыки:
- Astro;
- TypeScript;
- browser APIs;
- Web Workers / OffscreenCanvas;
- Cloudflare Pages / Workers;
- архитектура модулей;
- производительность;
- безопасность;
- CI/CD;
- переиспользование.

Обязательная установка:
готовое зрелое решение > адаптация > тонкий адаптер > собственное ядро.

### 3. SEO + поиск с ИИ + полевые исследования
Навыки:
- техническое SEO;
- архитектура URL;
- семантика и интент;
- индексация;
- canonical / sitemap / hreflang;
- Schema.org;
- внутренняя перелинковка;
- конкурентная выдача;
- GSC / Bing Webmaster / Яндекс Вебмастер;
- AI citations / mentions / recommendation tracking;
- query fan-out;
- экспериментальный дизайн;
- анализ форумов и практических кейсов.

Правило:
форумный пост = гипотеза, а не доказательство.

### 4. UX / продуктовый дизайнер
Навыки:
- пользовательские сценарии;
- состояния интерфейса;
- обратимость действий;
- ошибки/пустые/загрузочные состояния;
- desktop/mobile;
- доступность;
- пользовательская проверка.

### 5. CRO-специалист
Навыки:
- воронки;
- точки отвалов;
- формулировка гипотез;
- A/B при достаточном трафике;
- анализ поведения;
- Webvisor/session replay;
- статистическая дисциплина.

Формат любой CRO-гипотезы:
ИЗМЕНЕНИЕ → ОЖИДАЕМОЕ ПОВЕДЕНИЕ → МЕТРИКА → УСЛОВИЕ ОСТАНОВКИ.

### 6. Конверсионный копирайтер
Навыки:
- hero;
- CTA;
- onboarding;
- errors/success;
- landing copy;
- SEO answer-first passages;
- удаление шаблонного ИИ-языка.

Требование:
конкретное действие + конкретный результат + конкретное преимущество.

### 7. Арт-директор / веб-дизайнер
Навыки:
- информационная иерархия;
- типографика;
- responsive;
- визуальная система;
- продуктовые демонстрации;
- реальный интерфейс как главный визуальный материал;
- отсутствие шаблонного SaaS/AI-вида.

### 8. Аналитик продукта и экспериментов
Навыки:
- GA4;
- Яндекс Метрика;
- Webvisor;
- GSC;
- Bing Webmaster;
- UTM;
- события;
- воронки;
- когортный анализ;
- контроль качества данных.

### 9. QA / производительность / доступность
Подключается как обязательный приёмочный контур:
- Chrome DevTools;
- Lighthouse / Core Web Vitals;
- E2E;
- visual regression;
- keyboard/focus;
- console/network;
- реальные файлы;
- большие файлы;
- мобильные экраны.

### 10. Open Source / security / license scout
Отвечает за:
- GitHub repositories;
- Issues / Discussions / PR;
- npm;
- лицензии;
- security history;
- активность поддержки;
- bundle size;
- совместимость;
- запрет на изобретение существующей функции заново.

## Роли, которые НЕ надо держать постоянно

- отдельный специалист по motion;
- отдельный специалист по accessibility;
- отдельный специалист по лицензиям;
- отдельный специалист по Chrome Store;
- отдельный ML-инженер.

Они подключаются на соответствующем этапе как проверяющие или исполнители.

## Принцип принятия решения

Каждое улучшение проходит фильтр:

IMPACT × CONFIDENCE × REUSE
---------------------------
COST × COMPLEXITY × RISK

Сначала задачи с максимальной ожидаемой отдачей.
