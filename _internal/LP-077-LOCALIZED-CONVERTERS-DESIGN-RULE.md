# LP-077 — единый визуальный стандарт exact-конвертеров

Дата: 2026-09-09

## Решение

Пока идёт SEO/CRO/локализация существующих конвертеров, визуальный стиль фиксируется.

1. EN и локализованные exact-конвертеры используют одну визуальную систему: те же глобальные токены, классы, карточки, таблицы, FAQ и tool-shell.
2. Для локалей используется один повторно используемый локализованный layout, а не отдельная верстка на каждую страну.
3. Запрещены page-specific CSS-темы и декоративные эксперименты в процессе локализации.
4. CTA в расширения используют один общий паттерн и появляются только при подтверждённой релевантности.
5. Текущий перегруз страницы не лечим точечными редизайнами. После покрытия SEO/локалей/воронок делаем один системный проход по плотности и иерархии общего шаблона.

## Парето

Сначала: `SEO → рабочий инструмент → результат → релевантное расширение` при едином стиле. Затем одним общим изменением упрощаем визуальную систему, а не переделываем страницы по одной.
